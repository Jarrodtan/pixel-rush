Game Objective:
	Both light player and shadow player will need to find and collect all the
	light shards and shadow fragments respectively, which are scattered around
	the level, in order to clear the stage!

=====================================================================================

Light Player controls:
	A and D keys					Move left and right
	W key						Jump
        
Pls take note: Double Tap W key for a Double Jump!


Shadow Player controls:
	Left and Right keys				Move left and right
	Up key						Jump
        
Pls take note: Double Tap Up key for a Double Jump!


Game hotkeys:
	Escape key					return to main menu
        T key            				Toggle on/off UI Stats Display
	

Cheat Code keys:
        0 key                                          stop/resume game timer
        9 key					       toggle on/off unlimited health
